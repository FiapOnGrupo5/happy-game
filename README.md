# Happy Games Store

Plataforma web de jogos digitais desenvolvida no contexto academico da FIAP, com foco em experiencia de compra simples, catalogo organizado e evolucao para ciberseguranca e IA.

## Status do Projeto (MVP)

Implementado atualmente:
- Cadastro e login com sessao local (escopo frontend).
- Catalogo com busca e filtros por genero/plataforma.
- Carrinho de compras com atualizacao de quantidade e calculo de total.
- Checkout com validacoes de formulario e resumo de pedido.
- Documentacao tecnica e de processo em `docs/`.

Planejado para evolucao:
- Backend de autenticacao com hash de senha.
- Controle de acesso por token e logging de seguranca.
- Motor inicial de recomendacao para personalizacao.

## Estrutura do Repositorio

```text
HTML/          paginas da aplicacao
CSS/           estilos globais e por pagina
JavaScript/    logica de autenticacao, catalogo, carrinho e compra
Imagens/       assets visuais
docs/          documentacao tecnica, processo e entregas
```

## Como Executar

1. Abra o projeto no VS Code.
2. Execute com Live Server (ou Five Server) a partir de `HTML/index.html`.
3. Navegue pelas paginas para validar o fluxo: Home -> Catalogo -> Carrinho -> Compra.
